## 📁 Projetos

### 01 · [Poke API + Web Scraping](./01-Poke-API---Web-Scraping/)

> *"Aprendi mais com os erros do que com o código que funcionou."*

Tudo começou com uma tentativa de fazer web scraping no site oficial da Pokédex — e um aprendizado imediato: o site possui restrições explícitas contra acesso automatizado. Assim que identifiquei isso nos Termos de Uso, mudei de abordagem.

A solução? A **PokeAPI** — uma API RESTful pública e gratuita criada exatamente para esse tipo de aplicação. Com ela, construí um DataFrame personalizado da Pokédex explorando múltiplos endpoints: tipos, habilidades, espécies e cadeias evolutivas.

**O que aprendi:**
- ✔️ Ética e limites legais do web scraping
- ✔️ Consumo eficiente de APIs RESTful públicas
- ✔️ Estratégias de cache local para evitar sobrecarga de requisições
- ✔️ Exploração de múltiplos endpoints para enriquecer dados
- ✔️ Transformação de dados brutos em DataFrames limpos e estruturados

**Tecnologias:** `Python` · `Requests` · `Pandas` · `tqdm` · `time`

### 02 · [Login Screen](./02-Login-Screen/)

Interface gráfica de tela de login desenvolvida com foco em aprender criação de GUIs modernas com Python.

O projeto explora os recursos do **CustomTkinter** para componentes visuais contemporâneos e do **Pillow** para integração de imagens — resultando em uma interface com identidade visual própria, inspirada em boas práticas de UX/UI.

**Funcionalidades:**
- 🖥️ Interface gráfica moderna e amigável
- 🔐 Validação de login com feedback visual
- 👁️ Checkbox para mostrar/esconder a senha
- 🎨 Ícones personalizados nos campos de entrada
- 📐 Layout dividido em dois frames

**Tecnologias:** `Python 3` · `CustomTkinter` · `Pillow`
